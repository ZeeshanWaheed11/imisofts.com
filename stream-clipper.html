Stream Clipper finds the loud moments in a long stream, like a GTA 6 stream, writes down what was said with Whisper on your computer, and cuts 9:16 clips with the facecam on top, word-by-word captions, a title and the post text.

How it works

You type one sentence. It does the boring part.

Ask Claude Code something like "make five clips from this stream" and paste the link. Here is what happens next, step by step.

  1. 1

    Grabs only the sound

    It downloads the sound, not the video. Sound files are much smaller, so this part is quick.

  2. 2

    Listens for the loud parts

    Screams, laughs and big reactions make the volume jump. When the stream has a chat replay, it also checks where the chat went crazy.

  3. 3

    Writes down the words, only there

    Whisper runs on your computer for about one minute around each loud moment, not the whole stream.

  4. 4

    Claude picks the best ones

    Claude reads the moments like an editor would and picks the ones worth posting, with a reason for each.

  5. 5

    Cuts vertical clips

    1080 by 1920 clips with the facecam on top, the gameplay below, big word-by-word captions and a short title. No facecam found? It asks you where it is.

  6. 6

    Writes the post

    A caption, hashtags and a credit line for every clip, saved in posts.md, so you can copy, paste and post.

Before it cuts anything, Claude asks one question: are you allowed to clip this streamer? If the answer is no, it stops.

Real test run

We tested it on our own film, not someone else's stream.

Our 6 minute film about the internet, on GitHub's free Linux runner: an AMD EPYC 7763 with 2 processor cores, 7.7 GB of memory and no graphics card. Times change with the computer: an earlier run on a faster one took 101 s and 119 s.

What you need

Three things. Two of them are free.

  • A computer

    Mac, Windows or Linux with Python 3.9 or newer. No graphics card needed.

  • Claude Code

    The AI assistant that runs the tool for you. It comes with Claude's paid plans, like Pro.

  • The free skill

    A folder of instructions that teaches Claude a new job, plus the script that does the heavy work.

The skill uses two free tools: FFmpeg, which cuts the video, and Whisper, which turns speech into text. Both run on your computer. If FFmpeg is missing, the setup step tells you how to install it, and it installs the Python parts for you.

Install

Installing takes about a minute.

  1. Download the zip.
  2. Open Claude Code and drag the zip in.
  3. Type: install this skill

Prefer to do it yourself? Unzip it so the folder sits at ~/.claude/skills/stream-clipper/, with SKILL.md directly inside it.

Then ask Claude something like make five clips from this stream: <link> or find this week's biggest GTA 6 streams.

Run the steps yourself
python3 scripts/clipper.py setup
python3 scripts/clipper.py find "gta 6 stream"
python3 scripts/clipper.py analyze "<link or file>" \
  --work clipper-work/test
# Claude writes clipper-work/test/picks.json
python3 scripts/clipper.py render \

Clip fairly

The honest rules about money from clips

Clipping can pay, but the footage is not yours. Here is what to know before you post.

Clipping programs pay per view

Many streamers and brands run clipping programs. Whop says clippers in its Content Rewards campaigns are paid about $1 per 1,000 views on average, and each campaign sets its own rate. Source: Whop.

GTA 6 footage belongs to Rockstar

Rockstar's policy page says Take-Two generally doesn't object to fans using game footage for non-commercial use, that making money from the footage counts as commercial, and that videos can be taken down at any time. Read the policy.

Only clip streamers who allow it

Join their program first, follow their rules for tags, links and credit, and never repost the same clip again and again.

No story spoilers

Rockstar takes down videos that show the ending and cutscenes posted on their own. Clip the funny gameplay, not the story.

The good news: the tool works on any long video. Podcasts, talk shows, IRL streams and games that allow money from videos.

FAQ

Stream Clipper, answered

Quick answers to the questions people ask first.

Is Stream Clipper really free?

Yes. The skill is free under the MIT license. You run it with Claude Code, which comes with Claude's paid plans, like Pro. FFmpeg, Whisper and the other tools it uses are free.

Do I need API keys?

No. Whisper runs on your own computer, and the tool does not upload your video anywhere.

Which sites does it work with?

YouTube, Twitch, Kick and most other sites that the free yt-dlp tool supports, plus any video file on your computer.

How long does it take?

In our latest test on a basic cloud computer with 2 cores and no graphics card, finding the moments in our 6 minute film and writing down the words took 149 seconds, and cutting 3 clips with captions took 157 seconds. An earlier run on a faster computer took 101 and 119 seconds, so times change with the computer. A long stream takes longer to download, but Whisper still only writes down about one minute around each loud moment.

Can I make money clipping GTA 6 streams?

Many streamers and brands pay clippers for views through programs like Whop Content Rewards, where Whop says clippers are paid about $1 per 1,000 views on average. For GTA footage, read Rockstar's policy first: it says making money from the footage counts as commercial use, and that videos can be taken down at any time.

What if it cannot find the facecam?

It saves a check image for every clip with a box where it thinks the webcam is. If the box is wrong or missing, Claude asks you where the webcam is and cuts the clip again, or uses the full picture with a blurred background.

Does it work on Windows?

Yes. Install Python 3.9 or newer and FFmpeg (winget install Gyan.FFmpeg), then let Claude run the setup step. The same goes for Mac (brew install ffmpeg) and Linux.

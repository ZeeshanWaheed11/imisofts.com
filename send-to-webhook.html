What Send to Webhook does

Still copying web pages into your automations by hand? Send to Webhook sends any page, link, image or text you select to your own n8n, Make, Zapier or Clay workflow.

Step 1: get your webhook URL

First, get your webhook URL. In n8n, add a Webhook node, set it to POST, copy the Production URL, not the Test URL, and publish the workflow. In Make, Zapier or Clay, create a webhook trigger and copy its URL. It should start with https. Plain http only works for a local n8n.

Step 2: paste it, Allow, Send test

Paste it into the settings page that opens after you install, and click Save. Chrome asks once to allow that website. Click Allow. Then click Send test. A 200 and your workflow's reply mean it's connected.

Step 3: send a page, a selection or a link

Now, on any page, click the icon. You'll see the page and any text you selected. Add a note if you like, and click Send. Or right-click a page, link, image or selection, and choose Send to.

The JSON your workflow gets

Your workflow gets the same clean JSON every time: type, URL, title, selected text, your note and more. Need the words on the page too? Tick Include the page text.

Fixes and privacy

If something's wrong, it tells you how to fix it, like publishing your n8n workflow. It only sends when you ask, only to your webhook, and never reads password or card boxes. Send to Webhook. Free, by imisofts.

Setup

What a correct webhook URL looks like

The right URL matters most. Here is where to find it in each tool.

n8n
Add a Webhook node and set HTTP Method to POST. Copy the Production URL, which looks like https://your-n8n-domain/webhook/..., not the Test URL with /webhook-test/. Then publish the workflow.
Make
Webhooks, then Custom webhook. Copy the URL, which looks like https://hook.your-region.make.com/..., and switch the scenario on.
Zapier
Webhooks by Zapier, then Catch Hook. Copy the URL, which starts with https://hooks.zapier.com/hooks/catch/, and publish the Zap.
Clay
Add, then Webhooks, then Monitor webhook. Copy the URL, which starts with https://api.clay.com/v3/sources/webhook/.

It must start with https://. Plain http:// works only for local and private addresses, such as http://localhost:5678 for a self-hosted n8n. Building the workflow itself? Our guide to n8n automation for cold email walks through a full one.

FAQ

Questions about Send to Webhook

Is Send to Webhook free?

Yes. It is free, with no account, no sign-up and no paid plan.

Does it work with self-hosted n8n?

Yes. Paste your n8n Production URL. Webhook URLs must use https://, except local and private network addresses such as http://localhost:5678, 192.168.x.x or a .local name, which can use plain http://.

Why does my n8n webhook not answer?

Usually the workflow is not published, or the Test URL was copied. The Test URL, with /webhook-test/, only listens for 120 seconds after you click Listen for test event. Copy the Production URL, with /webhook/, set the Webhook node's HTTP Method to POST and publish the workflow. The extension tells you which of these it sees.

What exactly does it send?

One JSON object with the same 21 fields every time: the page address and title, any text you selected, your note, the page description and sharing tags, author, date, language, main heading, the link or image you right-clicked, and when and from where it was sent. The visible page text is added only when you turn it on, up to 20,000 characters.

Can I protect my webhook with a secret?

Yes. Add an optional secret header, such as an API key or token, and check it in your workflow. It is saved in your browser and sent only to that webhook.

How many webhooks can I add?

Up to 10, with one default. With more than one, the right-click menu lists them by name, and the popup lets you pick.

Is there a keyboard shortcut?

Yes. Alt+Shift+Y (Option+Shift+Y on a Mac) opens the popup. The shortcut that sends a page straight away has no default, so a page is never sent by accident. You can set one on Chrome's shortcuts page, chrome://extensions/shortcuts.

Does imisofts see the pages I send?

No. Pages go straight from your browser to the webhooks you add. imisofts runs no server for the extension and receives nothing. The details are in the extension privacy policy.
